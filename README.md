# METRO LIFE RP

Juego de rol urbano para Android y iPhone.

## Motor
Unity 6 con URP.

## Primera demo
- Ciudad ficticia inspirada en Monterrey, México.
- Personaje en tercera persona.
- Movimiento y cámara.
- Calles y edificios básicos.
- Punto de aparición en el centro.
- Controles táctiles para móviles.

## Estado
Proyecto en desarrollo. La escena y el juego todavía no están compilados ni probados.
